# Deterministic and agentic work

Use deterministic code for validation, identity, deduplication, authorization,
known-state reconciliation, retry policy, and invariant checks. These paths need
repeatability and clear failure modes.

Use agentic components for ambiguous classification, synthesis, hypothesis
generation, or drafting when their uncertainty can be bounded and reviewed.
Store an agent's output as an interpretation or proposed action, never as
unattributed evidence or implicit authority.

Promote recurring, verified patterns from agentic exploration into deterministic
mechanisms. Escalate when the state is ambiguous, authority is absent, or impact
is difficult to reverse.
