# Attention and autonomy

Human attention is a scarce input reserved for intent, judgment, consent, and
meaning. The environment should silently handle safe mechanical work, surface
important changes, and group decisions by urgency and reversibility.

Autonomy is capability-specific, not a resident-wide personality setting. A
resident may autonomously classify an artifact, be allowed to propose a calendar
change, and still require consent to execute it. Confidence never substitutes
for authority.

Good automation reduces the number of operational steps without concealing the
state needed to supervise it. **A feature should reduce operation, not relocate it.**
