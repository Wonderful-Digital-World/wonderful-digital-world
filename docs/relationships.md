# Relationships to independent projects

WDW defines the environment and seams; related projects retain their own scope,
repository, release cadence, and license.

- **Human Model** describes a human as portable evidence and explanation. It may
  serve a domain or resident role, but it is not WDW's persistent runtime.
- **Bridget** explores bounded continuity and interpretation. It is optional and
  never the mandatory interpreter of all evidence.
- **QA Agents** contributed reusable patterns—durable shared state, stable issue
  fingerprints, advisory routing, and explicit outcomes—without defining WDW.
- **World View / Tiny Places** may render authorized projections. It does not own
  canonical state or orchestrate the environment.

Integration occurs through versioned data and command contracts. No independent
project is imported merely to make a diagram appear complete.
