# Public and private boundary

**Open-source the architecture of the world. Keep the lived world private.**

Appropriate public material includes abstractions, contracts, invariants,
synthetic fixtures, diagrams, generic examples, and redacted architectural
history. Private material includes personal artifacts, memories, relationships,
health or financial state, credentials, private prompts, production identifiers,
and any dataset from which those can be reconstructed.

Publication is a transformation, not a repository copy. Each example should be
synthetic and each architectural claim should be checked against current code.
Historical documents provide rationale but do not override current contracts or
tests.
