# Interfaces

Interfaces are projections over the world, not the world itself. A command line,
ambient surface, native application, web page, or spatial scene may coexist if
each consumes a declared projection and sends bounded intents through an
authorized command boundary.

An interface should show freshness, uncertainty, pending decisions, blocked work,
and action outcomes. It must not create a second hidden state model merely to
make the presentation convenient.

This boundary enables multiple experiences—including World View / Tiny Places—
without coupling durable state to a renderer.
